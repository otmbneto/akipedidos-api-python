Web API AkiPedidos

Web API baseada em sessão que expõe funcionalidades do AkiPedidos/Pedlog através de endpoints HTTP. Todas as requisições exigem uma sessão válida.

Autenticação

POST /auth/login

Autentica um usuário e cria uma sessão.

{
  "email": "usuario@email.com",
  "password": "1234"
}
A resposta inclui um session_id. Ele deve ser enviado nas próximas requisições via header. 
{
  "accept": "application/json",
  "X-Session-Id": "uuid-session-id"
}

Exemplos de uso

curl -X POST http://api.pedlog.com/auth/login -H "Content-Type: application/json" -d "{\"email\":\"user@email.com\",\"password\":\"12345678\"}" --ssl-no-revoke
        
    import requests
    requests.post("https://api.pedlog.com/auth/login", data={
      "email": "user@email.com",
      "password": "12345678"
    })
